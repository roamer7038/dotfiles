# decide

## 手順
1. 用途のルーブリックが `~/.claude/skills/decide/rubrics/<用途>.md` にあれば使う。なければ下の形式で作り、再利用しそうなら保存する。
2. `Agent` を `subagent_type: "decider"` で呼ぶ。依頼文にルーブリック（またはそのパス）と、`id` 付きの対象リストを渡す。
3. 返り値の JSON を解析する。`escalate: true` の項目はメインで判断する。
4. escalate が多い場合はルーブリックの定義・境界例を見直す。

## ルーブリック形式
分類:
```
種類: 分類
ラベル:
- <label>: <定義>。例: <典型例>。境界: <紛らわしい例とどちらに入るか>
```
採点（数値の自由回帰はさせない）:
```
種類: 採点 1-5
観点: <何を評価するか>
1: <状態の記述>
3: <状態の記述>
5: <状態の記述>
```

## 返り値
`[{"id", "label"|null, "score"|null, "confidence", "reason", "escalate"}]`。`confidence < 0.7` とルーブリック外は `escalate: true`。
