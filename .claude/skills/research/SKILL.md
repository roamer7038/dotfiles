# research

メインセッションで長文を読まずに調査するための手順。

## 使い分け
| 状況 | 手段 |
|---|---|
| 1〜2 ページ・1 ファイルで済む | 直接読む、または `web-fetch` / `Explore`（`model: "haiku"`） |
| 複数ソースの照合が必要 | このスキル（`research-lead`） |
| 長い物語形式の報告書が必要 | `anthropic-skills:deep-research` |

## 手順
1. 依頼の目的・範囲が曖昧なら、委任前にユーザに確認する。
2. `Agent` を `subagent_type: "research-lead"` で呼ぶ。`model` は指定しない（定義の Sonnet を使う）。
3. 依頼文は下のテンプレートで書く。
4. 返ってきた報告の「矛盾・未解決」を確認し、必要なら追加調査を同じ手順で依頼する。
5. 再利用できる事実は wikictl に記録する。

## 依頼文テンプレート
```
目的: <この調査で何を決めたいか>
問い: <答えてほしいこと>
範囲: <対象サイト・リポジトリ・パス・期間>
除外: <調べなくてよいこと>
期待する出力: <結論に必要な粒度、比較表が必要か等>
```

## 返り値
`## 結論` / `## 根拠` / `## 矛盾・未解決` / `## 追加調査の提案` の 4 節。`needs_clarification:` が返ったら依頼文を補って再依頼する。
